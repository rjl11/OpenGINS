- [ ] **TM210: gyro bias vs temperature.** In the field, temperature sets the gyro bias random walk, not the bench Allan figure. The datasheet's ±0.004 °/s/°C is about 14 °/h per degree, so a 1 °C change per 10 min acts like about 3e-6 rad/s/√s, roughly 4× the bench upper bound of 7e-7. A longer static Allan log (about 45 h to resolve that bound) would only push `APP_GYR_BIAS_RW` lower, the wrong way for field use, so it is not planned. Instead, log a few hours across a temperature swing with the same tools (`tm210_allan_log.py` records the Status temperature): a cold start outdoors or in a fridge, then warm-up on the bench. Fit bias against temperature per axis and set the field value of `APP_GYR_BIAS_RW` (and check `APP_ACC_BIAS_RW`) from the bias rate at a realistic field temperature rate. Then check it in a drive replay with GNSS cut for 10 s and 30 s (`external/INSLIB/tools/replay.c`), with the setting at ×0.3, ×1 and ×5. See [plans/imu-tm210.md](plans/imu-tm210.md), "Calibration steps" (Temperature).
