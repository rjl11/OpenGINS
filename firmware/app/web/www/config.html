How long the filter keeps giving a position on the IMU alone after the last GNSS fix. Applies live, the filter keeps running.

Height offset filter: learns the barometer's offset to the GNSS height, which gives the absolute height during a GNSS outage. With the barometric INS height (see "INS height from") it also takes the barometer's weather drift back off the absolute height. 0 = INSLIB default. Applies live: the filter restarts. The barometer sigma is used, and shown, only with the barometric INS height.

Ethernet (W5500)

Wired output to AgOpenWeb / AgOpenGPS: $PAOGI at 10 Hz to the subnet broadcast on UDP 9999, RTCM from its NTRIP client on UDP 2233 to the receiver. Off = no module fitted; its pins are left alone. Applies live.

The front camera unit sends its flow to UDP 5800. AgOpenGPS / AgOpenWeb module scans on UDP 8888 are answered.

Corrections (RTCM)

Only one source feeds the receiver; the other's frames are dropped. Applies live.
